# ピアノ練習アプリ

自分で演奏を練習するためのWebアプリです。Chromeで `index.html` を開くと使えます。

- 現在の機能：画面鍵盤ピアノ、音名当てクイズ、鍵盤の位置当てクイズ、曲の練習
- 方針・構成：[CLAUDE.md](CLAUDE.md)
- 進捗：[docs/roadmap.md](docs/roadmap.md)
- 録音のピアノの音：[VCSL（Versilian Community Sample Library）](https://github.com/sgossner/VCSL) の Grand Piano, Steinway B（CC0）。詳しくは [sounds/README.md](sounds/README.md)
- Steinway は Steinway & Sons の登録商標です。このアプリは同社とは関係ありません
