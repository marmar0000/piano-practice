### ステップ2のメモ
- 片手ずつ練習・部分ループには「曲のデータ」「決まったタイミングで音を鳴らす仕組み」「鍵盤を光らせる表示」が必要。これらはお手本再生を作る中でできあがるので、お手本再生を先に作る順番に変えた（2-1 → 2-2 → 2-3）
- 曲データは右手・左手を分けて持てる形式にする
- 2-1（初版）でできたこと：モード「曲の練習」。曲を選んで再生すると、鳴っている音の鍵盤が光る（右手＝オレンジ、左手＝紫）。テンポは再生中でも変えられ、曲ごとに保存。鍵盤の位置は曲に合わせて自動で決まる（2段のときは右手を下段、左手を上段に）。収録曲：きらきら星、メリーさんのひつじ、よろこびの歌（著作権の切れた曲。左手の伴奏はこのアプリ用に付けたもの）
- 2-2で使える部品：曲データの右手・左手の区別（events の hand）、予約再生（playScheduled）、光る鍵盤（setLit）
- 2-3で使える部品：拍と時刻の変換（beatToTime / timeToBeat）。区間の最初の拍を基準にすればくり返せる
- 今後足せること：一時停止・途中から再生、カウント（再生前の「1・2・3・4」）、五線譜での表示、曲の追加

### ステップ3・4のメモ
- 音名当て：五線譜に出た音符の音名を答える。五線譜の描画（index.html の renderStaff）を使い回せる
- 位置当て：出題された音名の鍵盤をタップする。画面鍵盤をそのまま使える
- 2つのクイズは画面鍵盤と部品が共通なので、続けて作ると効率がよい
- 音名当て（初版）でできたこと：画面上の「モード」で鍵盤ピアノと切り替え。音部記号（ト音・ヘ音・両方）、出題範囲（加線なし・1本まで・2本まで）、答えの表記（ドレミ・CDE）を選べる。答えると音が鳴り、正解数・正解率・連続正解・最高記録を表示
- 音名当てで今後足せること：♯・♭の音も出題、苦手な音を多めに出題、制限時間モード
- 位置当て（初版）でできたこと：出題された音名の鍵盤を画面鍵盤（PCはキーボードも可）で押して答える。出題する音（白鍵だけ・黒鍵も）、音の高さ（どのオクターブでも正解・オクターブも当てる）、答えの表記（音名当てと共通）を選べる。押した音が鳴り、正解の鍵盤を緑・まちがえた鍵盤を赤で表示
- 位置当てで今後足せること：五線譜の音符で出題（音名当てと組み合わせ）、苦手な音を多めに出題

## 最初のステップから外したもの（機能候補には残す）
- マイクでの単音判定

## 実機確認で見つかった課題
- iPad縦向きで中央が空いて不自然 → 縦向きは鍵盤を2段にして対応（完了）
- ダブルタップすると画面が拡大される → CSSの指定と、短い間隔の2回目のタップを止める処理で対応（実機で確認待ち）
- しばらく使っていると音が出なくなった → iOSで音が中断された状態から戻れていなかったと推定。再開画面と作り直しで対応。実機ではChromeの再起動で直った（Chrome側の一時的な不調だった可能性もある）
