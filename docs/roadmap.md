### ステップ2のメモ
- 片手ずつ練習・部分ループには「曲のデータ」「決まったタイミングで音を鳴らす仕組み」「鍵盤を光らせる表示」が必要。これらはお手本再生を作る中でできあがるので、お手本再生を先に作る順番に変えた（2-1 → 2-2 → 2-3）
- 曲データは右手・左手を分けて持てる形式にする
- 2-1（初版）でできたこと：モード「曲の練習」。曲を選んで再生すると、鳴っている音の鍵盤が光る（右手＝オレンジ、左手＝紫）。テンポは再生中でも変えられ、曲ごとに保存。鍵盤の位置は曲に合わせて自動で決まる（2段のときは右手を下段、左手を上段に）。収録曲：きらきら星、メリーさんのひつじ、よろこびの歌（著作権の切れた曲。左手の伴奏はこのアプリ用に付けたもの）
- 2-2（初版）でできたこと：曲の練習で「両手（お手本）・右手・左手」を選べる。進み方は「弾くまで待つ」（次に弾く鍵盤が光り、正しく弾くまで止まって待つ。タイミングは判定しない）と「テンポ通り」（練習する手は鳴らさず光るだけ）。もう片方の手は「自動で鳴らす・鳴らさない」。弾くまで待つときはミスの数を数え、最後まで弾くと「最後まで弾けました！ミス○回」と出る
- 2-2であわせて直したこと：設定項目が増えてスマホで操作パネルが画面の半分を占めたので、「設定」ボタンでたためるようにした（スマホは最初からたたむ）。表示エリアの高さは中身に合わせて測るようにした
- 2-3（初版）でできたこと：曲の練習の画面で「○〜○小節」を選ぶと、その区間だけを練習できる（区間は曲ごとに保存）。「くり返し：オン」にすると区間の最後で最初に戻り、停止ボタンを押すまでくり返す。両手（お手本）・右手・左手、弾くまで待つ・テンポ通りのどれとも組み合わせられる。くり返し中は「○回目」を表示し、弾くまで待つときはその回のミスと前の回のミスを出す。くり返しがオフなら区間を1回弾いて止まる（「区間を弾けました！」）。鍵盤の位置は区間の音に合わせて決める
- 部分ループで今後足せること：うまく弾けたら（ミス0回など）少しずつテンポを上げる、くり返しの間に1小節分の間（カウント）を入れる、再生中にくり返しのオン・オフを切り替える
- 今後足せること：一時停止・途中から再生、カウント（再生前の「1・2・3・4」）、五線譜での表示、曲の追加、片手練習の記録（ミスの数の履歴）、ミスの多い場所の表示

### ステップ2-4・2-5のメモ（タイミング・音の長さの判定）
- ユーザーの希望：タイミングと音の長さを判定し、音ゲーのように評価を出したい。少しずれても先に進めるようにする
- 実装はブラウザでも可能。難しいのはスマホの遅れ（画面に触れてから届くまで＋スピーカーから音が出るまで）。iOSは特に遅れが大きく、Bluetoothイヤホンだと0.15〜0.25秒ほど遅れる
- 対策：
  - タイミング調整：一定のテンポのクリック音に合わせて8回ほどタップしてもらい、平均のずれを端末ごとに保存して、判定のときに差し引く
  - 判定の幅をゆるめにする（目安：パーフェクト ±0.06秒、グレート ±0.12秒、グッド ±0.2秒、それより外はミス）。速い曲で幅が音の間隔より広くならないよう、半拍を上限にする
  - 押した時刻はイベントの timeStamp を使い、AudioContext の getOutputTimestamp で音の時刻に直す（処理の遅れの影響を受けないように）
- 進み方に3つ目の「判定つき」を足す：テンポ通りに進み、練習する手の音ごとに判定する。グッドの幅を過ぎても弾かなければ止まって待つ（＝少しずれても進むが、大きく遅れたら待つ）
- 音の長さ：離した時刻を音の終わりと比べ、「短め・ちょうど・長め」をタイミングの評価とは別に出す（ピアノは音の長さの許容が広いので、ゆるめにする）
- 結果の表示：パーフェクト・グレート・グッド・ミスの数、正確さ（％）、曲・練習する手ごとの最高記録
- 評価の文言は日本語（カタカナ）にする（CLAUDE.md の「画面の文言はすべて日本語」）
- 実装するとき、CLAUDE.md の「厳密なリズム判定は避ける」を「判定はゆるめの幅とタイミング調整で行い、大きく遅れたら止まって待つ」に書き換える
- 2-3（部分ループ）の後に作る：苦手な区間をくり返しながら評価を上げる練習ができる
- 1回の作業を1機能にするため、タイミング（2-4）と音の長さ（2-5）に分けた
- 2-4（初版）でできたこと：片手練習の進み方に「判定つき」を追加。1小節分のカウント（クリック音）のあと、テンポ通りに進み、練習する手の音ごとにパーフェクト・グレート・グッド・ミスと「はやい・おそい」を出す。グッドの幅を過ぎても弾かなければミスにして、弾くまで止まって待つ。ちがう鍵盤を押したときもミスに数える。正確さ（％）を表示し、最後まで弾くと内訳・正確さ・最高記録（曲・練習する手・区間ごと）を出す。部分ループと組み合わせると、回ごとの正確さと前の回の正確さを出す
- 2-4の「タイミング調整」：判定つきのときに設定に出る。クリック音に合わせて8回タップすると、ずれの中央値を端末ごとに保存し、判定のときに差し引く
- 2-4であわせて直したこと：画面に入りきらないとき（スマホ横向きで設定を開いたときなど）、表示エリアが鍵盤や操作パネルと重なっていたので、重ならずに画面全体をスクロールできるようにした
- 2-5（初版）でできたこと：判定つきで、タイミングが当たった音（パーフェクト〜グッド）は、離したときに押していた時間を楽譜の長さと比べ、「長さ ちょうど・短め・長め」を出す。タイミングの判定とは別で、正確さ（％）には入れない。最後まで弾くと「音の長さ ちょうど○ 短め○ 長め○」を出す。判定つきのときは、色の見本（右手・左手）の行を音の長さの行に置きかえた（スマホ横向きで高さを増やさないため）
- 2-5で今後足せること：音の長さの判定のきびしさを選べるようにする、音の長さも最高記録に残す、押している間に「もう離してよい」ことがわかる表示（鍵盤の光り方を変えるなど）
- 2-4で今後足せること：判定の幅の「きびしさ」を選べるようにする、テンポ通り・弾くまで待つにもカウントを入れる、ミスの多い場所の表示

### ステップ3・4のメモ
- 音名当て：五線譜に出た音符の音名を答える。五線譜の描画（index.html の renderStaff）を使い回せる
- 位置当て：出題された音名の鍵盤をタップする。画面鍵盤をそのまま使える
- 2つのクイズは画面鍵盤と部品が共通なので、続けて作ると効率がよい
- 音名当て（初版）でできたこと：画面上の「モード」で鍵盤ピアノと切り替え。音部記号（ト音・ヘ音・両方）、出題範囲（加線なし・1本まで・2本まで）、答えの表記（ドレミ・CDE）を選べる。答えると音が鳴り、正解数・正解率・連続正解・最高記録を表示
- 音名当てで今後足せること：♯・♭の音も出題、苦手な音を多めに出題、制限時間モード
- 位置当て（初版）でできたこと：出題された音名の鍵盤を画面鍵盤（PCはキーボードも可）で押して答える。出題する音（白鍵だけ・黒鍵も）、音の高さ（どのオクターブでも正解・オクターブも当てる）、答えの表記（音名当てと共通）を選べる。押した音が鳴り、正解の鍵盤を緑・まちがえた鍵盤を赤で表示
- 位置当てで今後足せること：五線譜の音符で出題（音名当てと組み合わせ）、苦手な音を多めに出題

## 実機確認で見つかった課題
- iPad縦向きで中央が空いて不自然 → 縦向きは鍵盤を2段にして対応（完了）
- ダブルタップすると画面が拡大される → CSSの指定と、短い間隔の2回目のタップを止める処理で対応（実機で確認待ち）
- しばらく使っていると音が出なくなった → iOSで音が中断された状態から戻れていなかったと推定。再開画面と作り直しで対応。実機ではChromeの再起動で直った（Chrome側の一時的な不調だった可能性もある）
