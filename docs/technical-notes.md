# 技術メモ

## ブラウザの制約（詳細）
- iPhone・iPadのブラウザはChromeも含めてすべてWebKitで動く。Web MIDI APIはWebKitが未対応のため、iPadでMIDIを使うならネイティブアプリが必要
- スマホのブラウザでは、鍵盤を押してから音が出るまでにわずかな遅れが出ることがある。厳密なリズム判定は難しめ
- マイクでの単音判定はブラウザで十分可能。和音の判定は難しい（ネイティブでも難しい）
- iPhone・iPadは消音（マナーモード）だとブラウザの音が鳴らないことがある
  - 対策1：画面で案内を出す
  - 対策2：`navigator.audioSession.type = 'playback'` を設定する（対応している環境のみ効く）
- 自動再生制限：AudioContextはユーザーの操作（タップ）の中で開始・再開する必要がある
  - iOSでは「指が触れた瞬間（pointerdown・touchstart）」ではなく「指を離した・タップ完了（pointerup・touchend・click）」でないと開始できないことがある → 開始画面は click で受ける
- iOSではアプリを切り替えるとAudioContextが止まる（suspended / interrupted）ことがあり、`resume()` しても戻らない場合がある
  - 対策（index.html で実装済み）：操作のたびに再開を試み、0.6秒たっても戻らなければ「タップして音を再開」画面を出し、AudioContextを作り直す。画面に戻ってきたときに止まっていても同じ画面を出す
  - 開始時に無音を一瞬再生して、音の出力を確実に始める
- ダブルタップでの拡大：iOSは viewport の `user-scalable=no` を無視する
  - 対策（index.html で実装済み）：すべての部品に `touch-action: manipulation` を指定（鍵盤は `none`）。さらに予備として、0.35秒以内の2回目のタップは touchend で preventDefault し、ボタンの上なら click() を呼んでボタンの操作だけ行う（鍵盤・選択欄・スライダーは対象外）
  - 2本指で広げる拡大（ピンチ）は止めていない
- マイク（getUserMedia）はHTTPSでないと使えない（GitHub PagesはHTTPSなのでOK）

## 画面鍵盤ピアノの実装メモ（index.html）
- 音は外部ファイルを使わず、Web Audio APIのオシレーターで合成
  - ピアノ：倍音（サイン波）を重ね、高い倍音ほど早く減衰させる。低い音ほど長く響く
  - エレピ：FM合成（変調の強さを減衰させる）
  - オルガン：ドローバー風に倍音を重ね、押している間は鳴り続ける
  - シンセ：ノコギリ波2本（少しずらす）＋ローパスフィルター
- 出力：各音 → コンプレッサー（和音で大きくなりすぎないように）→ 音量 → ソフトクリップ（音割れ防止）→ スピーカー（index.html の buildOutput）
  - 音量はコンプレッサーの後ろでかける。スライダーの値 v（0〜1）に対して 1.6 × v^1.5 倍
  - ソフトクリップ：0.8を超えたところから、なめらかに1.0へ近づける（WaveShaper）
  - 測定値（音量70・ピアノ単音）：最大 −6.7dB。以前（−12.5dB）より約6dB大きい。8音の和音を音量100で弾いても最大 −0.1dB で、0dBを超えない
  - オルガン・シンセは他の音色と同じくらいの大きさになるよう、音色ごとの音量を調整済み
- タッチはPointer Eventsで処理。指ごとに押している鍵盤を記録し、指を滑らせると隣の鍵盤に移る（グリッサンド）
- サスティン中は鍵盤を離しても音を止めず、サスティンを切ったときに離している音だけ止める
- 鍵盤の数は画面幅と「鍵盤の大きさ」設定から自動で決める（縦向きスマホは1オクターブ程度、横向きiPadは2〜3オクターブ）
- 段数：「自動」のときは、縦向きで高さに余裕があれば2段にする（iPad縦向きなど）。下段＝基準の音域（右手）、上段＝そのすぐ下の音域（左手）。オクターブ移動は2段まとめて動く。設定で1段・2段に固定もできる
- 鍵盤の高さは白鍵の幅の6倍まで（実物のピアノに近い比率）。それ以上は伸ばさない
- PCのキーボードでも演奏できる（A〜;の段が白鍵、W・E・T・Y・U・O・Pが黒鍵、Z/Xでオクターブ移動、スペースを押している間サスティン）
- 表示エリア：「音名」「大譜表」「ト音記号」「ヘ音記号」を切り替えられる
  - 五線譜はSVGで描く。ト音記号・ヘ音記号・♯もフォントを使わずパスで描いている（端末によって形や位置がずれないように）
  - 音符は全音符。♯で表記（♭は未対応）。大譜表ではド4（C4）以上をト音記号、それより下をヘ音記号に書く
  - 2度でぶつかる音は右の列に、近い♯は左の列にずらす。五線から外れる音は加線を引き、表示範囲を広げる
- 設定（音色・音量・オクターブ・表示・音名表示・鍵盤の大きさ・段数・モード・クイズの設定）はlocalStorageの `piano-practice:settings` に保存

## 曲の練習（お手本再生＋光る鍵盤）の実装メモ（index.html）
- 曲データは index.html の `SONGS` に書く。1曲＝ `{ id, title, tempo, beatsPerBar, right, left }`。right・left は片手分の文字列
- 曲データの書き方：「音名オクターブ:拍数」をスペースで区切って並べる。「|」は小節の区切り
  - 例）`C4:1`（ド4を1拍）、`F#4:0.5`（ファ♯4を半拍）、`R:2`（2拍休み）、`C3+G3:4`（ド3とソ3を同時に4拍）
  - 拍数は4分音符＝1。音名はC〜B、♯は `#`（♭は未対応）
  - 小節の長さが拍子（beatsPerBar）と合わないときは、開発者ツールのコンソールに「曲データ「…」右手 3小節目：小節の長さが…」と注意が出る
- 読み込むと、音の並び `{ midis, beat（何拍目から）, dur（拍数）, hand（right / left） }` に変換される（parsePart）
- 再生：25ミリ秒ごとに、0.12秒先までの音を Web Audio API の時刻で予約する（タイマーのずれで音のタイミングが乱れないように）。予約した音は停止ボタンですぐ消せるよう記録しておく
- 同じ音が続いても聞き分けられるよう、音は0.03秒だけ短く鳴らす。光る時間は音の長さの9割
- テンポ変更：「この時刻に何拍目」という基準（anchorTime / anchorBeat）を持ち、テンポを変えたらいまの位置を新しい基準にする。再生中でも途切れずに速さが変わる
- 光る鍵盤：画面の更新（requestAnimationFrame）ごとに、いま鳴っている音を調べて光らせる。スピーカーから音が出るまでの遅れ（outputLatency）の分だけ表示を遅らせる。右手と左手が同じ音なら右手の色
- 鍵盤の位置：曲の音がいちばん多く入るオクターブを自動で選ぶ。2段のときは右手の音を下段、左手の音を上段で数える。オクターブボタンで動かせるが、保存しない（鍵盤ピアノのオクターブ設定とは別）。入りきらない音があれば停止中の表示で知らせる
- 曲の練習では自分で鍵盤を弾くこともできる（お手本に合わせて弾ける）。お手本の音は鍵盤を押した音とは別に管理している
- 画面を離れたら再生を止める
- 選んだ曲（songId）と曲ごとのテンポ（songTempos）は `piano-practice:settings` に保存

### 片手ずつ練習（2-2）
- 練習する手（songHand：both / right / left）、進み方（songAdvance：wait / tempo）、もう片方の手（songOther：play / mute）を `piano-practice:settings` に保存。設定を変えたら再生は止める
- 練習する手の音は、どちらの進み方でも予約再生しない（自分で弾いた音だけが鳴る）
- 弾くまで待つ：
  - 練習する手の音を同じ拍ごとにまとめた「弾くところ」（steps）を作る。次に弾くところの拍で時間を止めて待つ（playbackBeat が止まった拍を返す）
  - もう片方の手の音は、次に弾くところより前の拍の分だけ予約する。同じ拍の音は、弾いた瞬間に鳴らす
  - 和音は全部の音を押したら進む（順番・同時でなくてよい）。押したタイミングや長さは判定しない（スマホの遅れがあるため）
  - 早めに弾いたときは、その拍まで進める（間にあるもう片方の手の音は飛ばす）
  - 光っている鍵盤が画面に入っていないときは、同じ音名の鍵盤でも正解にする（スマホの1オクターブ表示で進めなくならないように）
  - 次に弾くところの音でない鍵盤を押すとミスとして数える
- 鍵盤の位置を自動で決めるとき、練習する手の音を10倍の重みで数える

### 部分ループ（2-3）
- 区間は曲ごとに `songRanges`（曲のid → { from, to }：小節の番号）として `piano-practice:settings` に保存。曲全体のときは記録しない。くり返すか（songLoop）は全曲共通
- songRange(song) が保存した区間を曲の長さに合わせて直して返す。rangeEvents(song) は区間に入っている音（区間の始まり以降に始まり、終わりより前に始まる音）を返し、区間の終わりをはみ出す音は終わりで切る（くり返したとき、次の回の音と重ならないように）
- くり返しは「拍を区間の長さずつ足して数え続ける」方式。n回目（0から）の音の拍＝曲の中の拍＋n×区間の長さ。テンポの基準（anchorTime / anchorBeat）や予約の仕組みはそのまま使える
  - 予約：peekBeat() が次に予約する音の拍を返す。区間の最後の音まで行ったら、音の番号を0に戻して回数（pass）を1増やす
  - 弾くまで待つ：currentStep() が次に弾くところの拍を返す。区間の最後まで弾いたら最初に戻り（stepPass を1増やす）、その回のミスの数を「前回」として残す
  - 光る鍵盤・小節の表示：いまの拍から何回目かを求め、曲の中の拍に直して調べる
- くり返さないときは、区間の終わりの拍で止まる（曲全体なら今までと同じ）
- 区間・くり返しを変えたら再生は止める（設定を変えたときと同じ）。区間を変えたら鍵盤の位置を区間の音に合わせ直す
- 始まりを終わりより後にしたら終わりを、終わりを始まりより前にしたら始まりを同じ小節に合わせる

## 操作パネルのたたみ・開き
- 「設定」ボタンで、よく使う項目（`data-main` を付けた項目：モード・曲・オクターブ・サスティン）以外をたためる
- 最初は画面の短い辺が600px以上（iPadなど）なら開き、それより小さい（スマホ）ならたたむ。切り替えたら `controlsOpen` として保存
- 開け閉めで操作パネルの高さが変わるので、鍵盤の大きさを合わせ直す（refitKeyboard）
- 表示エリアに残す高さ（displayMin）は、位置当てクイズ・曲の練習では表示の中身の高さを測って決める。鍵盤ピアノは最低90px

## 音名当てクイズの実装メモ（index.html）
- ♯のない音（白鍵の音）だけを出題し、7つのボタン（ドレミ／CDE）で答える
- 出題範囲は「五線の外にはみ出す音の数」で決める。加線なし＝第1線のすぐ下〜第5線のすぐ上（ト音記号ならレ4〜ソ5）、加線1本まで＝±3音、加線2本まで＝±5音（ト音記号ならソ3〜レ6、ヘ音記号ならシ1〜ファ4）
- 同じ問題が2回続かないようにしている
- 五線の表示範囲は出題範囲のいちばん高い音・低い音に合わせて固定（問題ごとに五線の大きさが変わらないように）
- 答えたら音符を緑（正解）／赤（不正解）にし、その音を0.9秒鳴らす。正解は0.8秒、不正解は2秒後に次の問題へ
- PCではC〜Bのキー、または1〜7のキーでも答えられる
- 最高連続正解数は音部記号・出題範囲の組み合わせごとに localStorage の `piano-practice:quiz-records` に保存。今回の成績（正解数・連続）は保存しない

## 鍵盤の位置当てクイズの実装メモ（index.html）
- 画面鍵盤をそのまま使う。指が触れた瞬間（pointerdown）の鍵盤で判定する。指を滑らせて移った鍵盤は判定しない（音は鳴る）。PCのキーボードで押しても判定する
- クイズ中は鍵盤の音名を出さない（答えたあと、正解の鍵盤にだけ出す）。ド4の青い点は目印として残す
- 「どのオクターブでも正解」：12音（白鍵だけなら7音）から出題し、同じ音名の鍵盤ならどれでも正解。正解の表示も同じ音名の鍵盤すべてを緑にする
- 「オクターブも当てる」：画面に出ている鍵盤から出題（ソ4のように番号付き）。オクターブ移動や画面の向きの変更で鍵盤の範囲が変わったら出題し直す（成績はそのまま）
- 問題・案内・成績の3行を出すため、表示エリアに残す高さは中身を測って決める（displayMin）
- サスティンは使わない（クイズ中は常にオフ）
- 最高連続正解数は `piano-practice:quiz-records` に `key-白鍵/黒鍵-オクターブ` の組み合わせごとに保存（音名当てと同じ場所）
- 「モード」（鍵盤ピアノ／音名当てクイズ／鍵盤の位置当てクイズ）で画面を切り替える。画面の部品や操作パネルの項目に `data-modes="piano keyQuiz"` のように表示するモードを書いておき、applyMode() で hidden を切り替える
- renderStaff(svg, 音のリスト, 譜表の種類, オプション) は描画先と譜表を引数で受け取るので、鍵盤ピアノの表示とクイズで共用している（オプション：音符を薄く・音符の色・表示範囲）
- 検索エンジンに載らないよう `<meta name="robots" content="noindex, nofollow">` を入れている。新しいHTMLページを作るときも同じ指定を入れる
