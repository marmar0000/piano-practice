# 作りたい機能の候補

## かんたん
- 画面鍵盤ピアノ（タッチで演奏、音色切り替え、オクターブ移動、サスティン）
- メトロノーム（テンポ・拍子・アクセント、だんだん速くなるモード）
- 音名当てクイズ（ト音記号・ヘ音記号）
- 鍵盤の位置当てクイズ
- コード表（構成音が鍵盤上で光り、音も鳴る）
- スケール表示（音階と指番号）
- 練習記録帳（日付・曲名・時間・メモ、累計時間、連続日数）
- 押している間だけ効くペダル（画面のペダル欄。iPadなど大きい画面。いまの切り替え式ボタンと設定で選べる）→ 作った（roadmap.md のステップ5-2）
- ソフトペダル（左のペダル：音を少し小さく・やわらかくする。音量を下げ、高い成分を少し削る）

## ふつう
- 聴音トレーニング（単音・和音・音程当て）
- リズム練習（流れる譜面に合わせてタップ、ズレ判定）
- 録音・再生、テンポを落として再生
- 本物に近いピアノの音（録音されたピアノ音源を読み込む）→ 作った（roadmap.md のステップ5。VCSL の Steinway B・CC0）
- お手本再生＋光る鍵盤
- 片手ずつ練習モード（右手だけ・左手だけを選んで練習。弾かない方の手は自動で鳴らすこともできる）
- 部分ループ練習（曲の一部の小節を指定して繰り返す。成功したら少しずつテンポアップ）
- 演奏のタイミング・音の長さの判定（音ゲーのようにパーフェクト・グレート・グッドを表示。タイミング調整つき。少しずれても先に進む）
- 初見練習用メロディの自動生成
- Bluetoothのフットペダル（楽譜めくり用のペダルの多くは、iPadからはキーボードのキー（矢印キー・PageDownなど）として見える。そのキーをサスティンとして受け取り、足で踏めるようにする。実機のペダルで確かめる必要がある）
- ソステヌートペダル（真ん中のペダル：踏んだ瞬間に押さえていた鍵盤の音だけ鳴り続け、あとから弾く音はふつうに止まる。使う曲は少ない）
- 練習タイマー（メニューを順番にこなす）

## 難しめ
- マイクで演奏判定（単音）
- MIDIキーボード連携（Android・PCのChromeのみ）
- 演奏の採点・分析（テンポの安定度、ミスの多い箇所をグラフ化）
- 楽譜（MusicXML）の表示と自動スクロール
- 落ちてくるノーツ表示（MIDIファイル読み込み）
- 自動伴奏（コード進行に合わせてドラム・ベース）
- 苦手克服カリキュラム（ミスの多い音・小節を優先出題）
- 曲データにペダル記号（踏む・離す）を入れ、楽譜に表示し、踏むタイミングを判定する（五線譜での表示（roadmap.md のステップ7）の後）

## 組み合わせ案
- 日替わり練習メニュー（スケール→聴音→曲練習）
- レベルアップ式（経験値で新しい曲やモードが解放）
